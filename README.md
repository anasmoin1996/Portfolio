# Ahmed's Portfolio

A personal portfolio website, designed with modern web aesthetics, glassmorphism, and dynamic animations.

## Features
- **Dynamic Blob Background**: Interactive cursor-following gradient blob.
- **Glassmorphism UI**: Beautiful frosted glass effects.
- **Micro-animations**: Hover effects and 3D card tilt effects.
- **Responsive Design**: Works gracefully on desktop and mobile devices.

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Run Locally
Just open `index.html` in your favorite browser.
