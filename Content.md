Suade (Blood Analysis Dashboard)
Project Description
Blood test results are often hard to read and easy to lose in PDF files. I built Suade to turn these PDFs into a visual "health dashboard." It extracts medical data from the documents and shows the user their health trends over time, like a "Spotify Wrapped" for their body.

Outcomes

- Created a prototype that turns messy PDF data into clean, easy-to-read graphs.
- Developed a way to track "Biological Age" based on historical health markers.
- Built a system that processes data privately without needing to store it long-term.

Tech Stack

- Data Extraction: Google Document AI (OCR) and Google Cloud Healthcare NLP.
- Processing: Python (using Medical Coding for LOINC/UMLS data).
- Environment: Google Cloud Platform (GCP).

What I Did

- Solved Technical Roadblocks: Fixed complex API errors by matching specific server regions and medical vocabularies.
- Medical Data Mapping: Linked raw test results to official medical codes so the data could be graphed accurately.
- Designed for Privacy: Built the app to be "ephemeral," meaning it reads the data, shows the results, and then clears the memory to keep user info safe.
